# An integrated landscape of environmental and genetic determinants of the plasma metabolome in 481,220 adults
## Description
This repository contains Linux/R code for the analysis implemented in the integrated atlas of environmental and genetic determinants of the human plasma metabolome, as described in the paper '[An integrated landscape of environmental and genetic determinants of the plasma metabolome in 481,220 adults](#citation)'.
