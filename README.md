# An integrated landscape of genetic and environmental determinants of the plasma metabolome
## Description
This repository contains Linux/R code for the analysis implemented in the integrated atlas of genetic and environmental determinants of the human plasma metabolome, as described in the paper '[An integrated landscape of genetic and environmental determinants of the plasma metabolome](#citation)'.
